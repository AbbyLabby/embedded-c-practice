# Function_Test

Demonstrates function usage by calculating the average of three integers.

## What it does

Prompts the user to enter three integers, then calculates and prints their integer average: `avg = (a + b + c) / 3`.

The project contains two versions of `main`:

- `main.c` — prompts for each number separately
- `main_new.c` — reads all three on one line

## Concepts

- Defining and calling functions
- Integer arithmetic
- Multiple source file variants

## Environment

Host (PC) — compiled with GCC via STM32CubeIDE host toolchain.
