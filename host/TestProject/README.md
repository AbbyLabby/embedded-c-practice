# TestProject

A minimal "Hello World" console application — the first C program in the course.

## What it does

Prints `Hello World` and `Press any button to exit` to the console, then waits for a keypress before exiting.

## Concepts

- Basic `printf` usage
- Program entry point (`main`)
- Console I/O with `getchar()`

## Environment

Host (PC) — compiled with GCC via STM32CubeIDE host toolchain.
