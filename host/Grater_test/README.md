# Grater_test

Compares two integers and prints which one is greater (or if they are equal).

## What it does

Reads two integers from the user and compares them using `if / else if / else`:

- Prints the greater number, or
- Reports that the numbers are equal.

## Concepts

- Multi-branch `if / else if / else`
- Comparison operators (`>`, `<`, `==`)
- Input validation

## Environment

Host (PC) — compiled with GCC via STM32CubeIDE host toolchain.
