# While_exc

Practice exercise for the `while` loop.

## What it does

Asks the user for a maximum value and prints all integers from 1 up to that value using a `while` loop.

## Concepts

- `while` loop
- Loop counters and increment operators
- Console output with `printf`

## Environment

Host (PC) — compiled with GCC via STM32CubeIDE host toolchain.
