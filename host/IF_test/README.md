# IF_test

A simple program demonstrating `if/else` conditional logic.

## What it does

Asks the user to enter their age and determines whether they are eligible to vote (age ≥ 18).

## Concepts

- `if / else` conditional statements
- `scanf` for user input
- Comparison operators

## Environment

Host (PC) — compiled with GCC via STM32CubeIDE host toolchain.
