# bitwise

Demonstrates all four basic bitwise operators on two user-provided integers.

## What it does

Reads two integers and prints the result of each bitwise operation:

| Operation | Operator |
|---|---|
| Bitwise AND | `val1 & val2` |
| Bitwise OR | `val1 \| val2` |
| Bitwise XOR | `val1 ^ val2` |
| Bitwise NOT (first value) | `~val1` |

## Concepts

- Bitwise AND, OR, XOR, NOT operators
- `uint32_t` for consistent 32-bit representation
- Importance of bitwise ops in embedded / low-level C

## Environment

Host (PC) — compiled with GCC via STM32CubeIDE host toolchain.
