# Asceii_print

Reads 6 characters from the console and prints their ASCII decimal values.

## What it does

Accepts 6 space-separated characters via `scanf`, stores them in an `int` array, and prints each character's numeric ASCII value using `printf("%d")`.

## Concepts

- Relationship between `char` values and their ASCII integer codes
- Reading characters with `scanf`
- Iterating over an array with `for`

## Example

Input: `A B C D E F`  
Output: `65 66 67 68 69 70`

## Environment

Host (PC) — compiled with GCC via STM32CubeIDE host toolchain.
