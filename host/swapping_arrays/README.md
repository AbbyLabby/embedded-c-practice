# swapping_arrays

Swaps the contents of two user-defined arrays using pointers.

## What it does

1. Asks the user for the sizes of two arrays.
2. Reads elements for each array from the console.
3. Swaps the arrays element-by-element using a pointer-based swap helper.
4. Prints both arrays before and after the swap.

## Concepts

- Variable-length arrays (VLA) in C99
- Passing arrays to functions via pointer
- Element-wise swap using a temporary variable
- Nested loops and indexed access

## Environment

Host (PC) — compiled with GCC via STM32CubeIDE host toolchain.
