# Tax_payable

A US federal income tax calculator implementing progressive tax brackets.

## What it does

Reads an annual income from the user and calculates the total tax payable based on US tax brackets (2018 rates). Each bracket is computed separately and the results are summed.

## Concepts

- Multi-branch `if / else if` logic for tax tiers
- Floating-point arithmetic
- Passing values to helper functions for bracket-level tax computation
- Practical application of conditionals

## Environment

Host (PC) — compiled with GCC via STM32CubeIDE host toolchain.
